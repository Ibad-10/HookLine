## 2. What the market tells us

### (a) Table stakes: nearly everyone has these

- Free advice grouped by scam type.
- A "scam or not?" multiple-choice quiz with an explanation after each answer (Jigsaw, Interland, Take Five, Stop! Think Fraud, ScamSpotter, Scotiabank).
- One short rule to remember (Stop, Challenge, Protect; slow down, check, stop).
- Where to report and get help (Action Fraud, AARP helpline, Age UK).
- Email alerts (Which?, AARP, FTC, Action Fraud).
- A "paste it and I'll check" tool (Genie, Scamio, McAfee, ScamAdviser, Get Safe Online). Hookline should link to these, not build one.

### (b) Differentiators: only a few have these

- **A path that adapts to each person:** Hoxhunt and Proofpoint (employees only); ScamSlayer (consumers, one city).
- **Two-way voice practice with branching:** Hoxhunt, Jericho, Adaptive. All are sold to employers.
- **Coaching straight after an attempt:** Hoxhunt.
- **Playing the scammer (prebunking):** *Bad News*, *Go Viral!*. This is the only group with published results.
- **Real victim stories with an expert:** Adaptive's free course, AARP's podcast.
- **Fresh content from real scams:** Proofpoint (reported emails become simulations), Which? (weekly).
- **Built for older users:** ScamSpotter's large text, Adaptive's 14 languages, Age UK's human help.
- **A family safe phrase:** Starling, Voicinne.

### (c) Gaps nobody fills well

1. **Voice practice for ordinary people.** Two-way AI voice practice exists only for employees. Individuals get a choice between two clips (Scotiabank), one-way surprise robocalls (Singapore) or hackathon prototypes (Voicinne). None of the sources I found, consumer or enterprise, describes stopping a call when the learner starts giving real details.
2. **This week's scams turned into practice.** Weekly alerts exist (Which?, FTC, IC3) but people can only read them. Training products work from fixed libraries. I found nothing that turns this week's alerts into a lesson, a quiz and a call.
3. **Memory for each person.** Prebunking wears off without boosters [36], yet consumer tools are one-shot: an 8-email quiz, a 20-minute course, a single quiz. Weak-spot tracking exists only in enterprise tools and ScamSlayer, and no consumer product I found schedules spaced repeats.
4. **Honest proof that it works.** Almost every figure is a vendor claim, and SATA is still raising money for its study. A real learning curve would stand out.
5. **No shaming.** Enterprise tools use failure pages; Singapore's game uses a leaderboard. There is room for a product with a kind tone.
