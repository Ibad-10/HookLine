# Hookline H0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build every H0 row of `docs/BACKLOG.md`: a scam-spotting web app with lessons from this week's reports, a browser voice practice call guarded by the Gatekeeper, a weak-spot profile, and a "with vs without Mubit" dashboard.

**Architecture:** One Next.js app (App Router) for UI and API routes. All LLM calls go through one function, `callLLM`, which talks to the Mubit gateway with the OpenAI SDK, logs cost, tokens and timing per call, and validates output with zod. Pure logic (Gatekeeper, profile, schedule, matcher, carbon, brand check) lives in small `src/lib` modules with unit tests; pages stay thin.

**Tech Stack:** Node 24, Next.js 16.4, TypeScript, Tailwind, `openai` 7.x (pointed at Mubit), `zod` 4.x, `@libsql/client` 0.18 (local file in dev, Turso in prod), `@elevenlabs/elevenlabs-js` 2.x (build-time TTS, Scribe token), `@elevenlabs/client` 1.x (browser Scribe), Vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-24-hookline-design.md`, `docs/BACKLOG.md` (H0 table), research in `docs/research/`.

## Global Constraints

- Every LLM call goes through `callLLM` and the Mubit gateway. No direct provider URLs.
- System prompts are constants in `src/lib/tasks/*.ts`; per-call text goes only in the user message. Changing a system prompt after Task 4 splits the Mubit task: don't.
- Models: frontier `gpt-6-luna` on `MUBIT_OPENAI_BASE_URL`; small stand-in `openai/gpt-oss-20b` on `MUBIT_GROQ_BASE_URL`. Overridable by `TEACHER_MODEL` / `COACH_MODEL` / `SMALL_MODEL`.
- Send `metadata: { session_id }` on every call (per learner or per call session).
- Generated lessons, quizzes and call lines use fictional brands only; `checkBrands` fails closed.
- Gatekeeper runs in the browser before any network call with user text; only masked text ever leaves the browser except raw audio to Scribe.
- Never store raw user turns. Logs store `stopped at step N` and masked text only.
- No wording "you failed", no public ranking, no "scam-proof" badge.
- Every practice screen shows a "Practice" label.
- Large-text setting scales all text; tap targets at least 48px; captions on by default.
- Carbon is shown as an estimate with range and method; never as a measurement.
- Commits as `Ibad Ullah Zuberi <99681549+Ibad-10@users.noreply.github.com>`, no Claude trailer. `.env` never committed.

## Review Focus

1. Speech-to-text writes numbers as words ("four two seven one...") or with spaces/dashes: Gatekeeper must still catch them. Test in Task 2.
2. LLM returns invalid JSON or off-schema output: caller gets a typed failure and the UI shows a fallback lesson, never a crash. Test in Task 3.
3. Mic permission denied, Scribe token fails, or browser lacks audio: call continues with the type-your-reply box. Test in Task 9 (pure state machine test with `input: "typed"`).
4. A user says "is this real?" or "I'm scared" mid-call: call ends kindly and counts as a pass. Test in Task 8.
5. A brief from a scraped page contains "ignore previous instructions": stays in the user message, output still schema-checked, brand check still runs. Test in Task 5.
